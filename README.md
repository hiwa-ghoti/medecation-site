# 薬局.com

ちいさなおなやみに、架空のおくすりを処方するエンターテインメントサイト。採用モックに合わせ、お悩み１の3択 → お悩み２の4択 → 結果の構成です。医療上の診断や実際の医薬品とは関係ありません。

## 起動方法

`index.html` をブラウザーで開くだけで使えます。インストール・ビルド・サーバー・通信は不要です。インターネットに接続せずに動作します。

## ファイル構成

```text
medecation-site/
├── index.html                  # 共通ヘッダー・進行表示・フッター
├── css/                        # 共通スタイル・手描きデザイン・「現実」画面
├── js/
│   ├── data.js                 # 質問・選択肢・12通りの結果の対応
│   ├── app.js                  # 画面表示・状態管理・イベント
│   └── medicine-result.js      # 薬の結果画面と文言
├── assets/images/
│   ├── capsule.svg             # オリジナルのアイコン
│   ├── question-bird.webp      # 質問画面の店員
│   ├── result-bird.webp        # 結果画面の店員
│   ├── reality.webp            # 「現実」の結果画像
│   └── medicines/              # 5種類の薬のイラスト
└── README.md
```

質問画面の手描きのお薬は、ローカルで直接開いても表示されるように、SVGシンボルを `index.html` に収録しています。

## 仕様・編集方法

- HTML・CSS・JavaScriptのみ。外部ライブラリー、フォント配信、API、データベースは使用していません。
- 最初の3択は `data.js` の `diagnosisData`、お悩み２の4択は `followupData` にあります。両方の回答から `resultByAnswers` で結果を決め、`resultNames` の名前を表示します。
- 通常結果では、回答に対応する薬を白背景に1件表示します。結果の紹介文とイラストは `js/medicine-result.js` にあります。「ない」から「ないってば！」を選んだ場合は、添付の手描き画像 `assets/images/reality.webp` を黒い画面に表示します。
- 画面遷移中は入力をロックし、連打による二重遷移を防ぎます。戻る際には下位の選択状態をクリアします。
- 各画面の「もどる」「えらびなおす」「もういっかい診断する」およびロゴで移動します。ブラウザーの履歴は追加しません。
- Tab/Shift+Tabで移動、Enter/Spaceでボタンを操作できます。切り替え時に見出しへフォーカスを移します。
- `prefers-reduced-motion: reduce` に対応しています。
- 診断結果の安定した `resultId` を使って、将来SNS共有を追加できます。初期実装では共有、個人情報の収集、データ保存は行いません。
- システムにある日本語フォント（UDデジタル教科書体など）を使用するため、OSごとに字形が変わり、画像モックとは完全には一致しません。フォント配信やフォントの再配布は行っていません。

## 確認

JavaScriptの構文、現在の全12経路の結果対応、連打防止、戻る・選び直し・再診断、フォーカス移動と架空表記をNode.js上のDOM代替環境で確認しています。実ブラウザーの目視確認とは別の検証です。

## 公開について

`index.html` を直接開いて使える静的サイトです。ソースコードは `hiwa-ghoti/medecation-site` の `main` ブランチで管理します。Webサイトの外部公開設定は行っていません。
